# Career 2026 (V1.4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Young scores (under 182 days old at pull time) stop moving the career line and forecast. The forecast also gets a 2026 check: a per-role hit rate in the artifact and a per-person "from films up to 2025 we said…" line on the track-record card.

**Architecture:**
- **Settled rule:** one SQL fragment, `SETTLED` in `backend/app/repo/career.py`, decides "settled".
- **API:** `career_films` returns a `settling` flag, and `career_response` builds the line, best film and forecast from counted films only. It also builds a `check` for films after `MODEL_DATA_MAX_YEAR` with the same `track_record()`.
- **Artifact:** the backtest adds a `holdout` block per role, built through its existing `evaluate()`. The artifact becomes version 2.
- **Frontend:** a settling dot style, one explanation sentence and a check line on the card.

**Tech Stack:** Python 3.11, SQLite, NumPy, FastAPI + Pydantic; React 19 + TypeScript, Recharts, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-31-career-2026-design.md` (read it alongside this plan).

## Global Constraints

- **Settled:** `pulled_at` date − `release_date` ≥ 182 days. `SETTLE_DAYS = INCOMPLETE_DAYS` (imported from `ml.data.clean`, never a literal). No `release_date` or no `pulled_at` → settled.
- **Counted film** = `rated and not settling`. Only counted films feed `line`, `best_film`, `forecast` and the check's history.
- **Unchanged:**
  - `RATED`, `roles_available`, `population_stats`, recipes and the model endpoints;
  - h, k, q and every 2019+ `test` number in the artifact;
  - fresh (`added`) films stay out (`BUILT`).
- **Cut year:** `MODEL_DATA_MAX_YEAR` (2025). The check's history is counted films with `year <= MODEL_DATA_MAX_YEAR`; check films are rated films with `year > MODEL_DATA_MAX_YEAR`.
- **Holdout block:** `{year_from, coverage, mae, baseline_mae, n_people, n_points}`, with `year_from = MODEL_DATA_MAX_YEAR + 1`.
  - Settled later films only.
  - Population numbers are the artifact's `mu` and `sigma_pop` for every point.
  - Equal weight per person; nothing tuned on it.
- **Artifact:** `VERSION = 2`. Loading requires `holdout` and its fields.
- **Copy, exactly:**
  - Explanation: `We also checked films from {year_from}, which the forecast never saw: {N} out of 10 of {n_points} landed inside.` With fewer than 100 points it ends `… landed inside (a small sample).` With `coverage` null there is no sentence. N = coverage rounded to the nearest 10%, as the 2019 sentence.
  - Check line: `From films up to {MODEL_DATA_MAX_YEAR} we said {low} – {high}.`, then per film `{Title} scored {score}{ so far (still settling)}, {inside|outside}.` The range uses the card's own `points(low) – points(high)` format; the title links to `/movies/:id`.
  - Tooltip line for a settling film: `Score still settling`.

## Review Focus

1. **A settling film is the person's highest score** (e.g. a 2026 film at 8.9). It must not become `best_film` and must not raise the forecast → test in Task 1.
2. **Exactly 5 rated films, one of them settling.** The main forecast must say `not_enough_films`, not quietly forecast from 5 → test in Task 1.
3. **`pulled_at` stored with time and zone** (`2026-10-30T13:42:39+00:00`). The age must use its date part; 181 vs 182 days is the boundary → test in Task 1.
4. **Later films that are all low-vote.** `check` must be `null` (no rated later film), never a line with no films → test in Task 3.
5. **A role with no 2026 points.** The artifact holds `coverage: null`, loading still works, and the frontend shows no 2026 sentence (never "NaN out of 10") → tests in Tasks 2 and 4.

### Task 2: Holdout in the backtest, artifact v2

**Files:**
- Modify: `ml/career/backtest.py`, `backend/app/services/career/forecast.py` (`ROLE_FIELDS`, holdout check in `load_career_artifact`), `ml/artifacts/career_forecast.json`

**Interfaces:**
- Consumes: `SETTLED` (Task 1); the existing `Point`, `evaluate(points, s, pop)`.
- Produces:
  - `HOLDOUT_FROM = MODEL_DATA_MAX_YEAR + 1`
  - `VERSION = 2`
  - `holdout_points(con, role: Role, min_votes: int) -> list[Point]`:
    - one `Point` per rated, settled film with `year >= HOLDOUT_FROM`;
    - `history` = the person's rated, settled films with `year <= MODEL_DATA_MAX_YEAR`, as (year, score), oldest first, one per film; points need `len(history) >= MIN_RATED`;
    - `weight` = 1 / that person's holdout points.
  - `roles.<role>.holdout`: `{year_from, coverage, mae, baseline_mae, n_people, n_points}`.
    - Built from `evaluate(holdout_points(...), s, lambda _y: (mu, sigma_pop))`, with `mu` and `sigma_pop` exactly as written to the artifact.
    - Floats rounded to 4 places, as `test`.
  - `load_career_artifact` fails when `holdout` or one of its fields is missing, naming the file and `make career`, as today.
