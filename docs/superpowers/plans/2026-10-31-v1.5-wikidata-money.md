# V1.5 Wikidata Money Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Wikidata budgets and worldwide box office (fill, replace flagged values, cross-check) plus a targeted TMDB pull of films Wikidata says have money, all checked in `clean.py` before storage; then retune, retrain and keep v2 only if revenue improves like for like.

**Architecture:** `ml/data/wikidata.py` pulls raw statements to `data/raw/wikidata_money.jsonl`; `ml/data/fx.py` builds and reads `data/fx_rates.csv`; `ml/data/wikidata_money.py` turns statements into one nominal-USD budget/revenue per film; `money_rules` in `ml/data/clean.py` merges them with TMDB before the existing rules. `ml/eval/compare_v2.py` freezes v1's per-film predictions and judges v2 against them.

**Tech Stack:** Python 3.11, pandas, httpx (sync), SQLite, LightGBM, Optuna, pytest; Wikidata Query Service (SPARQL), World Bank API.

**Spec:** `docs/superpowers/specs/2026-10-31-v1.5-wikidata-money-design.md`

## Global Constraints

- Nothing is written to `data/movies.db` that has not passed `clean.py`; the build still goes temp file → swap.
- Box office: worldwide only (region qualifier = worldwide, or the single value with no region qualifier).
- Disagreement threshold: 3× in 2025 dollars (`WIKIDATA_DISAGREE = 3.0`); budget ambiguity threshold: 2× (`BUDGET_AMBIGUOUS = 2.0`).
- Currencies: the fixed list from the survey (≥ 50 films) plus FRF, DEM, ITL, ESP; euro fixed rates FRF 6.55957, DEM 1.95583, ITL 1936.27, ESP 166.386.
- Wikidata is used only for films with year 1960–2025 (`MODEL_DATA_MAX_YEAR`); 2026 films are untouched.
- Optuna: same folds 1–2, `--minutes 15` per target.
- Keep rule: revenue lower than v1 on validation and backtest mean, like for like; revenue validation coverage 77–83%; budget and score no worse than v1 by more than the backtest std.
- Docker memory < ~450 MB.
- All network steps run on Dimitris's PC. Wikidata User-Agent: `MoviePredictionApp/1.5 (https://github.com/Tsomaros)`.
- Commits end with the session's Co-Authored-By / Claude-Session lines.

## Review Focus

1. **A film with several publication dates (P577) in different years** comes back from two year queries → statements deduplicated by statement id (Task 2).
2. **Amount strings like `"+1.5E8"` or `"+2500000.75"`** → parsed as float and rounded to an int; non-numeric amounts skipped and counted (Task 1).
3. **A currency/year with no FX row** (EUR before 1999, a currency only listed from 1980) → value dropped and counted as `wikidata_fx_missing`, never a crash or a 0 (Task 4).
4. **Non-numeric or TV-style TMDB ids in P4947** (e.g. `"tv/1234"`) → skipped in `pull`, never appended in `new-ids` (Task 2).
5. **A Wikidata value for a 2026 film** (year > 2025) → ignored by the merge; the film keeps exactly its TMDB money (Task 5).

```sparql
SELECT ?st ?item ?tmdb ?prop ?amount ?iso ?rank ?region ?time WHERE {
  ?item wdt:P4947 ?tmdb ; wdt:P577 ?date .
  FILTER(YEAR(?date) = {year})
  { ?item p:P2142 ?st . ?st psv:P2142 ?v . BIND("box_office" AS ?prop) }
  UNION
  { ?item p:P2130 ?st . ?st psv:P2130 ?v . BIND("budget" AS ?prop) }
  ?v wikibase:quantityAmount ?amount ; wikibase:quantityUnit ?unit .
  OPTIONAL { ?unit wdt:P498 ?iso }
  ?st wikibase:rank ?rank .
  OPTIONAL { ?st pq:P3005 ?region }
  OPTIONAL { ?st pq:P585 ?time }
}
```
  `survey` runs one aggregate query per decade (same pattern, `GROUP BY ?iso` counting distinct `?item`, and `GROUP BY ?region` counting `?st`) and writes `SURVEY_FILE`. CLI: `uv run python -m ml.data.wikidata survey`.

### Task 3: Exchange rates

**Files:**
- Create: `ml/data/fx.py`
- Test: `tests/data/test_fx.py`

**Interfaces:**
- Produces:
  - `FX_FILE = Path("data/fx_rates.csv")` (columns `currency,year,per_usd`)

  - `CURRENCY_COUNTRY: dict[str, str]` World Bank country code per currency: `EUR→EMU, GBP→GBR, JPY→JPN, INR→IND, CNY→CHN, KRW→KOR, FRF→FRA, DEM→DEU, ITL→ITA, ESP→ESP`; extended in Task 7 from the survey.

  - `build_fx(years: range, out: Path = FX_FILE) -> int`: World Bank indicator `PA.NUS.FCRF` per country (`https://api.worldbank.org/v2/country/{code}/indicator/PA.NUS.FCRF?format=json&per_page=200&date=1960:2025`). For FRF/DEM/ITL/ESP: if the country's 1990 value is < 2 the series is in euro-equivalents, so multiply by `EURO_FIXED[c]`; keep only years ≤ 1998 for them. CLI: `uv run python -m ml.data.fx build`.

**Interfaces:**
- Consumes: Task 1 statement dicts (from `RAW_WIKIDATA`), Task 3 `load_fx`, `to_usd`.

  - `load_statements(path: Path = RAW_WIKIDATA) -> list[dict]` (skips marker lines)
  - `select_money(statements: list[dict], fx: dict) -> tuple[pd.DataFrame, dict[str, int]]` → columns `id` (TMDB id), `wd_budget`, `wd_revenue` (nominal USD, `Int64`, NULL when none), `year`; report keys `wikidata_region_dropped`, `wikidata_currency_dropped`, `wikidata_fx_missing`, `wikidata_budget_ambiguous`.

Rules (apply per film and property, in this order): preferred rank beats normal → box office keeps region `== WORLDWIDE`, or the untagged statement when it is the film's only box office statement; anything else is `region_dropped` → convert each with `to_usd` (currency not in the FX table → `currency_dropped`; currency known but year missing → `fx_missing`) → box office: latest `point_in_time` (None sorts first) → budget: if max/min of the remaining values > `BUDGET_AMBIGUOUS` drop all (`budget_ambiguous`), else latest.

Order inside `money_rules`, per column (`budget`, `revenue`), for films with `year <= MODEL_DATA_MAX_YEAR` only:
1. Placeholder rule on TMDB values (as today).
2. TMDB-only suspicion on the TMDB values (existing low-ratio and currency-cap tests): `currency` marks the budget bad, `low_ratio` marks the revenue bad.
3. Missing TMDB value → Wikidata (`filled`); TMDB value marked bad and Wikidata present → Wikidata (`replaced`); both good → compare in 2025 dollars: ratio > `WIKIDATA_DISAGREE` either way → `disagree` (keep TMDB), else `confirmed`.
4. 2025 dollars, low-ratio, currency cap and incomplete rules recomputed on the final values (a replaced pair that still fails stays flagged); `money_suspect` also true where step 3 found `disagree`.
5. Report keys: `wikidata_budget_filled`, `wikidata_revenue_filled`, `wikidata_budget_replaced`, `wikidata_revenue_replaced`, `wikidata_confirmed`, `money_suspect_wikidata_disagree`.
